# stm32-freertos-lcd12864-proteus

作业2实现：基于 STM32F103 + FreeRTOS + LCD12864 + 4x4 矩阵键盘（九宫格/T9 多击输入）。

## 1. 工程结构

> 当前仓库未携带完整 Keil/IAR 工程文件，本次补充了可直接复用的模块化源码骨架。

```text
Inc/
  app_tasks.h        # 任务通信结构、任务创建入口
  keypad.h           # 矩阵键盘扫描/消抖/按键事件定义
  t9_input.h         # T9 输入法与文本编辑状态机
  lcd12864.h         # LCD12864 驱动抽象接口
Src/
  main.c             # FreeRTOS 启动入口（对接 HAL/SystemClock）
  app_tasks.c        # 键盘任务/输入任务/LCD 刷新任务
  keypad.c           # 行列扫描 + 消抖 + 连按事件
  t9_input.c         # 多击超时、大小写/数字模式、删除与回车
  lcd12864.c         # LCD 初始化/清屏/定位/写入/帧渲染
```

## 2. 如何编译

按你现有工具链集成本仓库源码：

- **Keil MDK**：将 `Inc/` 添加到 Include Path，将 `Src/*.c` 加入工程；确保链接 FreeRTOS 与 STM32 HAL。
- **IAR**：同理添加头文件路径与源码组。
- **CubeMX + Makefile**：把 `Src/` 与 `Inc/` 合并进 `Core/Src`、`Core/Inc` 后重新生成工程并编译。

> 说明：本仓库当前不含独立 CI/单元测试脚本，编译验证依赖你的本地 STM32 工程环境。

## 3. Proteus 连接说明（推荐）

### 3.1 LCD12864（并口模式，示例）

| LCD12864 引脚 | 功能 | STM32F103 引脚（示例） |
|---|---|---|
| RS | 指令/数据选择 | PB0 |
| RW | 读写控制（建议固定写） | PB1（或直接接 GND） |
| E  | 使能 | PB10 |
| D0..D7 | 数据总线 | PA0..PA7 |
| VSS | GND | GND |
| VDD | 电源 | 5V/3.3V（按模块要求） |
| V0  | 对比度 | 10K 电位器中点 |
| BLA/BLK | 背光 | 5V/GND |

### 3.2 4x4 矩阵键盘（行列扫描）

| 键盘引脚 | STM32F103 引脚（示例） |
|---|---|
| R0 | PB12 |
| R1 | PB13 |
| R2 | PB14 |
| R3 | PB15 |
| C0 | PB3  |
| C1 | PB4  |
| C2 | PB5  |
| C3 | PB6  |

> 行口配置为推挽输出，列口配置为上拉输入。扫描时逐行拉低读取列状态。

## 4. 键位映射（九宫格 + 功能键）

默认逻辑键盘（4x4）：

```text
[1] [2] [3] [Del]
[4] [5] [6] [Mode]
[7] [8] [9] [Enter]
[*] [0] [#] [Reserved]
```

- `2 -> ABC/abc`
- `3 -> DEF/def`
- `4 -> GHI/ghi`
- `5 -> JKL/jkl`
- `6 -> MNO/mno`
- `7 -> PQRS/pqrs`
- `8 -> TUV/tuv`
- `9 -> WXYZ/wxyz`
- `Mode`：`ABC -> abc -> 123 -> ABC` 循环
- `Del`：删除上一个字符（若存在待确认多击字符，优先删除待确认字符）
- `Enter`：确认当前多击字符并换行
- `1/*/#/0`：按当前模式处理（`123` 模式直接输出数字；字母模式下 `0` 输出空格）

## 5. 输入法规则

- **多击超时阈值**：`800ms`（可在 `Src/t9_input.c` 调整）。
- 同一数字键在超时内重复短按：在同组字母内循环。
- 超时或按下不同键：自动确认上一字符并开始新字符。
- 支持：
  - 数字直接输入（`123` 模式）
  - 大写输入（示例：`1ABC1ABC...`）
  - 小写输入（示例：`1abc1abc...`）
  - 删除上一个字符
  - 回车换行与自动滚动显示（保留状态栏 + 3 行文本窗口）

## 6. FreeRTOS 任务设计

- `KeypadTask`：周期扫描矩阵键盘、消抖、短按/连按事件识别，投递 `KeyEvent` 到队列。
- `InputTask`：消费按键事件，运行 T9 文本编辑状态机，生成 `DisplayFrame`。
- `LcdTask`：消费显示帧并刷新 LCD（避免忙等，阻塞式等待队列）。

任务间通信全部通过队列完成，避免轮询忙等。

## 7. 仿真预期效果

上电后首行显示模式状态（例如 `T9 ABC`），输入区域实时回显：

- 按 `Mode` 可切换 `ABC/abc/123`
- 按数字键可执行 T9 多击输入
- `Del` 可回删
- `Enter` 可换行
- 长文本会自动滚动，不破坏显示布局
